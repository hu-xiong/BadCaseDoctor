## 二、引流怎么走（防限流）

不要在小红书/抖音评论区硬发「加微信/扫码/闲鱼链接」。

推荐路径：

1. 内容讲痛点 + 给半成品干货（步骤截图、对比表）
2. 结尾钩子：「要现成可跑的 / 不会搭的，主页看置顶」或「私信发：智能体」
3. 私信里说：闲鱼搜你的店名/商品关键词，或发闲鱼口令（平台规则允许的方式）
4. 闲鱼侧：擦亮 + 秒回 + ¥10 意向金筛选

- [ ] 擦亮 1 次（有流量时多擦）

## 四、闲鱼私聊话术（复制）

**开场**
> 你好，智能体一般按场景报：简单扣子 Bot 99 起；知识库/工作流 300 起；Dify/接系统 800 起。你跟我说下：给谁用、要解决啥、有没有现成资料？

**对方只会「搭个客服」**
> 可以。你是要网页对话，还是小红书/店铺私信？有没有产品 FAQ？我按资料做知识库+人设，先出一版你试用再定稿。

**对方砍价**
> 页上 10 块是意向沟通。正式做按工作量，简单单可以走 99–199，复杂带对接另算。你把场景发我，我给一口价。

**成交定金**
> 定金支付宝扫码开工（可发收款码）。约定范围内含 1–2 轮小改；模型 API / 服务器费你自理。
