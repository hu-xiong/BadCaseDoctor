# 需求说明：首轮「思考」出现前的前置时间与链路拆解

**版本**：2026-03-30  
**目的**：界定「用户发送消息 → 第一条**可见**思考/规划正文」之间的耗时由哪些环节构成；明确 **TODO/规划仅在判定需工具链之后** 才生成，避免「先挂占位再发现纯聊」的无效耗时。  
**范围**：ReAct 流式（`agents/react_simplified.py` 中 `_run_stream_raw`）、SSE（`routers/agent.py`）、前端（`consumeAgentSseV1Chunk.js`、`applyReactThinkSSEStepEvent.js`、`AgentTaskRun.vue`）。

---

## 1. 名词约定

| 名词 | 含义 |
|------|------|
| **首包** | 浏览器收到 SSE 后先消费的 JSON（`hello`、`phase` 等），仅连接与阶段提示。 |
| **工具意图** | 本轮是否需要走 grep/modify/THINK 等；**必须先于**生成可执行 TODO 列表判定（见 §2.2）。 |
| **首轮 THINK** | 在确认走工具链后，用大模型生成规划（`REACT_THINK_CONTENT_ONLY=1` 时主输出多为 `todos_stream`）。 |
| **合并门控** | `REACT_TOOLS_INTENT_MERGE_INTO_THINK=1`（默认）：启发式未判死「需工具」时，**不单独调门控模型**，首轮流中 **先** `[GATE]{...}[/GATE]` **再** `<todo_list>`，语义与独立门控 JSON 一致；纯聊在 `[GATE]` 内即结束，**不产生 TODO**。 |
| **独立门控** | 上述合并关闭时：`react_tools_intent_classify_sync` 在 THINK 前判定；通过后由 `REACT_THINK_PRELUDE`（默认开）在 THINK 首 token 前推一行可见 `reasoning`（`react_think_prelude_after_gate`）。 |
| **占位 step** | 前端仅在 **首轮 THINK 出现可见内容之后**（`reasoning` 非零宽字符或 `todos_stream`）才挂 `_placeholderSteps`，**不在 `hello` 挂**，避免纯聊路径「先占位再清空」。 |
| **步骤 Thought / agent_thought** | 每步 **decide** 阶段的 `agent_thought` 等，发生在 `todo_start` 之后；与首轮 THINK 流不是同一事件。 |

---

## 2. 端到端时序（工具链主路径）

### 2.1 前端 → 后端

1. 发起 Agent SSE；`hello` + `phase(think)` 尽快下发。  
2. **不再**在消费 `hello`/`phase` 时创建占位 `steps`（见 `consumeAgentSseV1Chunk.js`）。

### 2.2 `_run_stream_raw` 入口（判定 → 再规划）

| 序号 | 步骤 | 说明 |
|------|------|------|
| A1 | `gather`：项目/计划名 + `format_tools` | 与门控 task 可并行（视启发式是否建门控 task）。 |
| A2 | 低信息量 / 改 vs 建澄清 | 命中则 **return**，无 THINK。 |
| A3 | **工具意图** | **默认合并门控**：同一轮 THINK 内先 `[GATE]` 再 todo；**关闭合并**时独立门控 LLM；启发式已「需工具」则跳过门控 LLM。 |
| A4 | 纯聊 | `intent_clarification` + `summary_stream` + `done`，**不产生 todos**。 |
| A5 | **STEP1 THINK** | 仅当确认走工具链；独立门控模式下可先发一行 `reasoning` 可见 prelude（合并模式下不发，避免与 `[GATE]` 叠句）。 |

**原则**：不存在「先生成完整 TODO 再隐藏」的主路径；未确认工具链前不会下发可执行 `todos` 事件。

### 2.3 首轮 THINK 流

- 子线程拉流 → `reasoning` / `todos_stream` → 前端在 **首段可见 reasoning 或任意 todos_stream** 时 `ensureFirstStepPlaceholder`，再 `syncPlaceholderStepThought` 镜像到 `steps[0]`。

### 2.4 到「步骤上 agent_thought」

- `todo_start` → decide 流 **`agent_thought`**。首条可见 agent_thought 取决于该步模型，与首轮 THINK 并行关系见 `REACT_DECIDE_FC_INSTANT_HINT` 等。

## 3. 环境变量速查

| 变量 | 含义 | 默认 |
|------|------|------|
| `REACT_TOOLS_INTENT_MERGE_INTO_THINK` | 合并门控进首轮 THINK | **1** |
| `REACT_THINK_PRELUDE` | 独立门控通过后、THINK 首 token 前可见 prelude | **1** |
| `REACT_TOOLS_INTENT_ENABLED` | 是否做语义门控 | 1 |
| `REACT_TOOLS_INTENT_HEURISTIC` | 启发式短路门控 LLM | 1 |

完整列表见 `react_simplified.py` 文件头。
